# Proposal Specialist: Checklist

## Before starting
- [ ] Discovery notes and deal plan read; approver and deadline known
- [ ] the owner's rate card version and date recorded, or "no rate card: placeholders" noted
- [ ] Solution sketch and dependency table received for non-template work
- [ ] Estimate with ranges received for custom work
- [ ] the owner's standard terms file located
- [ ] Client-supplied contract or PO terms routed to `contract-review-assistant`
- [ ] the owner's GST registration status confirmed or marked unknown

## While working
- [ ] Format chosen from the table (one-page, standard, phased)
- [ ] Every scope line has deliverable, limit and "done when"
- [ ] Revision rounds stated per stage and what counts as a round
- [ ] Refinement vs new module table included
- [ ] Exclusions library applied; every reasonable owner assumption covered
- [ ] Each assumption states its consequence if not true
- [ ] Every amount cites a rate card line and version, or is a visible placeholder
- [ ] Options and discounts only as supplied by `pricing-strategist` with approval recorded
- [ ] Third-party services in a separate table with payer and dated rate source
- [ ] Milestones tied to observable events; no "on satisfaction" triggers
- [ ] Terms pulled from the standard file; non-standard clauses flagged
- [ ] Narrative sections from `proposal-writer` merged without changing scope wording

## Before handoff
- [ ] Line items sum to the total; milestone shares total 100% and amounts match to the rupee
- [ ] Every discovery must-have is in scope, a later phase or an exclusion
- [ ] Scope, estimate and solution sketch agree
- [ ] Header has proposal number, version, date and valid-until date
- [ ] No GSTIN, entity name, address or bank details unless supplied by the owner
- [ ] Indian number format used (₹1,50,000); no em dashes
- [ ] Risk note written for the owner with open placeholders listed
- [ ] Version log updated
- [ ] No PDF produced before the owner approves wording
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] Asked to fill a price that is not on the rate card
- [ ] Asked to add a discount, free extra or changed milestone without approval
- [ ] Asked to add GST or tax wording before status is confirmed
- [ ] Asked to send the proposal or share it outside the team
