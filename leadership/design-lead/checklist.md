# Design Lead: Checklist

## Before starting
- [ ] Brief read: business, audience, primary action, budget band, deadline
- [ ] Project tier assigned (T1 to T4) with a reason
- [ ] Budget confirmed to cover the gates the tier requires
- [ ] Client brand guidelines checked for conflicts with the quality bar
- [ ] Regional language need identified (Telugu, Hindi, other)
- [ ] Designer roster load checked

## While working
- [ ] One owner designer named; contributors only where the tier needs them
- [ ] Reviewer named at kickoff and is not the producer
- [ ] Gate dates set and shared with `project-manager`
- [ ] Evidence list per gate copied into the project plan
- [ ] Mobile 375 px required first at G1 and G2
- [ ] Script-capable reviewer named for regional-language projects
- [ ] Font coverage for Telugu or Devanagari tested before type approval
- [ ] Disputes settled in evidence order and recorded as decisions
- [ ] Per-screen issues routed to `design-reviewer`, not reviewed by the lead
- [ ] Recurring review findings counted monthly

## Before handoff
- [ ] Project design plan complete: tier, owner, reviewer, gates, risks
- [ ] Designer load at or under 2 active T2+ projects each
- [ ] Standards changelog entry links to the review reports that drove it
- [ ] Image, font and illustration rights routed to `licensing-ip-assistant`
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A client deadline would skip G2 or G4
- [ ] A client insists on an anti-generic pattern as part of their brand
- [ ] A paid seat, freelancer or asset license is needed
- [ ] The only available reviewer produced the design
