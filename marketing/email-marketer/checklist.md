# Email Marketer: Checklist

## Before starting
- [ ] Goal of the campaign written in one sentence
- [ ] Sender name, domain and physical address confirmed for the footer
- [ ] List source recorded for every segment; consent record present
- [ ] Segment rule written and the count of contacts recorded
- [ ] Hold check: no purchased, scraped or shared third-party list in the segment
- [ ] Sender authentication (SPF, DKIM, DMARC) confirmed on the sending domain
- [ ] Channel check done: WhatsApp or SMS considered where it fits the message better

## Offer and copy
- [ ] Offer has price, expiry and terms, with an as-of date
- [ ] Call to action page is live before the send
- [ ] Subject line is 40 to 60 characters; three options drafted
- [ ] Preview text is 90 to 140 characters and does not repeat the subject
- [ ] One call to action in the body
- [ ] No AI-tell patterns: no contrast reveals, negation lists, stock openers or sign-off filler
- [ ] No em dashes in subject or preview text
- [ ] Every claim listed with a source in the brief

## Languages and rendering
- [ ] Telugu or Hindi versions reviewed by a native speaker before send
- [ ] Test render checked on a mid-range Android phone and a second email client
- [ ] Unsubscribe link tested and working before send
- [ ] Footer carries sender identity, physical address and reason for receiving

## Send and test
- [ ] Test send to the client review list
- [ ] Send time set in IST, outside late-night hours
- [ ] A/B test (if any) has one variable, a sample size and a decision rule written before send
- [ ] Ramp plan set for a new domain (small batch first, increase over 2 to 3 weeks)

## After send
- [ ] Hard bounces removed from the list the same day
- [ ] Complaint rate and bounce rate recorded for the send
- [ ] Report delivered at 48 hours and 7 days with conversions
- [ ] List log updated with additions, removals and reasons

## Stop and escalate if
- [ ] Complaint rate above 0.3 percent: stop sends to that list and escalate to Kiran
- [ ] The list has no consent record for the segment
- [ ] The offer is regulated (loans, insurance, health, supplements, financial products)
- [ ] Sender domain fails authentication after two fix attempts
