# WF-18: Reels Planning and Production

Plan one Reel or Short and leave a package that can be filmed. Export a video only when the tool and the media exist.

## Inputs
- Brand id, platform, and target length under 90 seconds.
- The idea and the assets the owner can record.
- Permission for any client screen.
- Authorization. Default is a package, not a post and not an ad spend.

## Specialists
`reels-producer` owns the package. `short-form-video-strategist` reviews the cut when it will be public and may set the series context first. `editor` reviews the spoken words. `scriptwriter` takes scripts over 90 seconds instead of this workflow.

## Parallel and sequential stages
Brand reading and the concept note can run together. The script, storyboard, and shot list are sequential because each depends on the previous line. Caption text can be written in parallel with the export checklist after the script is locked. They use different files.

| Stage | Owner | Depends on | Parallel with | Deliverable | Validation | Approval |
|---|---|---|---|---|---|---|
| Concept | `short-form-video-strategist` | none | Brand note by `reels-producer` | structure and length | one idea | producer if the structure needs footage that does not exist |
| Script | `reels-producer` | Concept | none | voiceover and three hooks | word budget for the length | `editor` |
| Storyboard | `reels-producer` | Script | none | timed frames | first 1.5 seconds carries the hook | `short-form-video-strategist` |
| Captions | `reels-producer` | Script | Export notes | caption text | readable muted | `editor` |
| Export notes | `reels-producer` | Script | Captions | settings and status | "video export was not run" unless a file exists | brand owner to publish |

## Deliverables
Hook, script, storyboard, shot list, captions, export note.

## Validations
Word count versus length. Missing assets marked missing. No mp4 claim without a file.

## Approval gates
Publishing, paid audio, and boosts need the owner.

## Exit criteria
The package is complete as instructions, or a real video path is listed because the export ran.

## Example invocation
"Run WF-18 for example-brand. A 30 second screen Reel on a homepage hero. Do not export video."
