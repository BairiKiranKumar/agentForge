# Content Repurposing Specialist: Checklist

## Before starting
- [ ] Source path exists and was read
- [ ] Brand id is a single profile and was loaded
- [ ] Permission limits and forbidden claims are written down
- [ ] Platform list is short enough for the source
- [ ] Authorization is still none unless the brief says otherwise

## While working
- [ ] Digest states one idea and the allowed proof
- [ ] Matrix has an owner, a hook, and a unique path per row
- [ ] Hooks are not the same sentence on every platform
- [ ] LinkedIn, carousel, Threads, and Reel rows differ in form
- [ ] Parallel rows do not share an output file
- [ ] No fact appears that the digest did not allow
- [ ] Missing artifacts are listed as missing, not described as done
- [ ] Client limits survived every cut

## Before handoff
- [ ] `editor` reviewed the package
- [ ] `index.md` links only to files on disk
- [ ] Calendar rows are drafts for `social-media-manager`, not a live schedule
- [ ] Handoff uses `orchestration/handoff-format.md`

## Stop and escalate if
- [ ] The owner demands identical captions on every platform
- [ ] The source is another brand's private material
- [ ] A row needs an invented metric to match the others
- [ ] The task includes publishing or spending
