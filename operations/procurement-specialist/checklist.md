# Procurement Specialist Checklist

## Before starting
- [ ] Review incoming purchase requisition for complete business justification and technical criteria
- [ ] Confirm approved budget code and expenditure ceiling with `budgeting-specialist`
- [ ] Verify number of required user seats or estimated consumption volume
- [ ] Check if an existing enterprise tool already satisfies the requested capability
- [ ] Determine required security compliance standards (SOC2, ISO 27001, DPDP Act 2023)
- [ ] Determine purchase threshold tier to establish required number of quotes (1, 2, or 3)

## While working
- [ ] Solicit formal written quotations or pricing proposals from candidate vendors
- [ ] Build weighted vendor evaluation matrix comparing features, usability, and SLAs
- [ ] Calculate Total Cost of Ownership (TCO) in INR including 18% GST and forex markups
- [ ] Identify Indian tax implications: GST Input Tax Credit eligibility, RCM liability, and TDS
- [ ] Negotiate annual commitment discounts, implementation fee waivers, or free seat buffers
- [ ] Check vendor contract for auto-renewal traps, termination notice windows, and price escalations
- [ ] Verify vendor payment terms (Net 30, corporate credit card, wire transfer)

## Before handoff
- [ ] Compile Purchase Recommendation Dossier with comparative scoring and TCO breakdown
- [ ] Ensure all vendor prices and calculations are verified and documented
- [ ] Secure legal contract review from `contract-review-assistant` for software terms
- [ ] Obtain formal budget approval from `budgeting-specialist`
- [ ] Archive all vendor quotes, emails, and evaluation sheets in procurement repository
- [ ] Confirm zero em dashes are present in any documentation
- [ ] Hand over signed documentation to `vendor-manager` and `invoicing-specialist`

## Stop and escalate if
- [ ] Vendor quotation exceeds approved departmental budget ceiling by more than 10%
- [ ] Vendor refuses to provide standard security documentation or violates data privacy policies
- [ ] Vendor insists on non-standard payment mechanisms that bypass company accounting controls
- [ ] Sole-source vendor presents predatory renewal price increase (>25%)
