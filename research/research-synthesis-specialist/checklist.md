# Research Synthesis Specialist: Checklist

## Before starting
- [ ] Research questions and decision served are known
- [ ] Raw notes or transcripts available (not only a summary)
- [ ] Data cleaned of names, phone numbers and faces
- [ ] Participant table with segment, channel and language available
- [ ] Prior insights on the topic located

## While working
- [ ] All data read once before coding
- [ ] Codebook kept with one-line definitions
- [ ] Every observation coded with participant ID, source and Did/Said type
- [ ] Second coder used on a sample for studies above about 8 participants
- [ ] Clusters formed bottom-up; outliers kept visible
- [ ] Clusters holding two ideas split
- [ ] Themes reviewed against the data, not memory
- [ ] Insights written as segment, behavior, because, implication
- [ ] Counts as n of N per segment, unprompted versus prompted where relevant
- [ ] Contradicting observations searched for and listed
- [ ] Confidence assigned per the rule table
- [ ] Single critical observations reported as risks
- [ ] Original-language quotes kept where meaning could shift
- [ ] Triangulated with other methods or studies where available

## Before handoff
- [ ] 3 to 7 insights, each tied to the decision
- [ ] No percentages from samples under 20
- [ ] Recommendations framed as options for the decision owner
- [ ] Limits section covers sampling bias, language and gaps
- [ ] Report submitted to `research-lead`; insight library updated
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] Asked to reach a predetermined conclusion
- [ ] Only summaries exist and a High-confidence result is expected
- [ ] Data contains personal details that were not cleaned
