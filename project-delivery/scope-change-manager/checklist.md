# Scope Change Manager Checklist

## Before starting
- [ ] Review executed Statement of Work (SOW), technical specifications, and documented exclusions
- [ ] Confirm baseline scope boundaries and milestone acceptance criteria with `delivery-manager`
- [ ] Initialize Master Change Request Register in central project repository
- [ ] Establish communication protocol with client stakeholders regarding formal change intake
- [ ] Align with `project-manager` to ensure sprint backlogs reflect only baseline SOW tasks

## While working
- [ ] Log incoming variation requests in CR register within 24 hours of receipt
- [ ] Conduct objective Scope Boundary Audit comparing requested feature against SOW clauses
- [ ] Classify variation as Defect (covered by warranty/SOW) or Billable Scope Change
- [ ] Coordinate with `estimation-specialist` and `technical-lead` to quantify effort delta
- [ ] Evaluate critical-path schedule impact with `project-manager` (milestone date deltas)
- [ ] Model additional fees in INR based on standard rate cards + 18% GST
- [ ] Draft formal Change Order Amendment following the standardized skeleton
- [ ] Present Change Order to client executive sponsor alongside `delivery-manager`
- [ ] Track approval signatures and update CR register status to Approved or Rejected

## Before handoff
- [ ] Secure dual-signed Change Order Amendment before releasing tasks to engineering
- [ ] Notify `project-manager` to inject approved tasks into upcoming sprint planning
- [ ] Update project milestone forecast dates and baseline scope documentation
- [ ] Transmit signed Change Order to `invoicing-specialist` for milestone billing setup
- [ ] Confirm zero em dashes are present in any change control documentation
- [ ] Format handoff according to `orchestration/handoff-format.md` standards

## Stop and escalate if
- [ ] Client demands immediate implementation of out-of-scope work while refusing to sign Change Order
- [ ] Cumulative change requests exceed 25% of original contract value, destabilizing the engagement
- [ ] Client disputes basic SOW boundary definitions, threatening legal breach or contract termination
