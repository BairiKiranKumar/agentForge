# WhatsApp Business Specialist: Checklist

## Before starting
- [ ] Business facts confirmed: name, category, address, hours, languages
- [ ] Phone number decided (dedicated or personal); chat backup noted if converting a personal number
- [ ] Who answers chats and daily volume recorded
- [ ] Prices confirmed by the owner, or "price on request"
- [ ] Every existing contact list has a recorded opt-in source, or is excluded
- [ ] Sensitive data cases (school children, clinic patients) flagged for `privacy-specialist`

## While working
- [ ] App or Platform decision written with reasons
- [ ] For Platform: Meta's pricing page fetched and the check date recorded
- [ ] No rupee rate stated without a rate card link and date
- [ ] Profile, catalog, greeting and away messages written
- [ ] Labels include New enquiry, Booked, Follow up, Paid, Completed, STOP offers
- [ ] 8 to 12 quick replies, each under 60 words, in the customer's language
- [ ] Click-to-chat links use 91 plus number, no "+" or spaces, URL-encoded text
- [ ] One prefilled message per source (website, Instagram, QR, creator)
- [ ] Each link tested on an Android phone and an iPhone with the date
- [ ] Opt-in wording names the business, WhatsApp and message types; checkbox unchecked by default
- [ ] Broadcast rules set: opted-in only, 2 to 4 promos a month, no sends 21:00 to 09:00 IST
- [ ] Every promotional message or template has a STOP line
- [ ] Template categories justified; no offers inside utility templates
- [ ] Template drafts include realistic sample values

## Before handoff
- [ ] Owner daily routine written
- [ ] Site button placement sent to `frontend-developer`; click events to `web-analytics-specialist`
- [ ] Platform integration to `integration-engineer`; journeys to `lifecycle-marketer`
- [ ] Telugu text sent to `localization-specialist`
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] Asked to message bought lists or contacts with no opt-in
- [ ] Asked to use an unofficial bulk sender or "WhatsApp blaster"
- [ ] Asked for the owner's WhatsApp OTP or login
- [ ] Health, student or financial data would be shared over WhatsApp without review
- [ ] Platform or BSP spend would start without approval
