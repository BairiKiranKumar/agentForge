# Program Manager Checklist

## Before starting
- [ ] Ingest strategic program charter, overarching business objectives, and key client milestones
- [ ] Identify all constituent projects, workstreams, and assigned project managers
- [ ] Establish centralized cross-project dependency tracking repository and communication channels
- [ ] Align sprint cadences and review schedules across all participating engineering teams
- [ ] Confirm shared resource availability and capacity constraints with `resource-planner`

## While working
- [ ] Build and maintain Master Program Roadmap showing all workstreams and integration gates
- [ ] Facilitate weekly cross-project coordination syncs with all project managers and technical leads
- [ ] Track cross-stream dependencies; enforce interface freeze dates and mock contract delivery
- [ ] Aggregate risks from individual project RAID logs into the Master Program Risk Matrix
- [ ] Resolve shared resource conflicts by aligning allocations with the critical program path
- [ ] Track end-to-end integration milestones connecting frontend applications to core backend APIs
- [ ] Verify that all constituent project documentation adheres to zero em dash standard

## Before handoff
- [ ] Publish bi-weekly Executive Program Status Report with macro RAG ratings and milestone forecasts
- [ ] Coordinate multi-stream user acceptance testing schedules with `acceptance-coordinator`
- [ ] Align integrated release cutover plans with `release-engineer` and `devops-engineer`
- [ ] Archive program governance decisions and updated roadmaps in central knowledge base
- [ ] Format handoff according to `orchestration/handoff-format.md` standards

## Stop and escalate if
- [ ] Critical foundational workstream slips beyond schedule buffers, directly threatening the program launch
- [ ] Architectural incompatibility between parallel streams requires major unbudgeted redesign
- [ ] Unresolved resource conflict between projects causes critical-path delivery stoppage
