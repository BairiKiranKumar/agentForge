# Resource Planner Checklist

## Before starting
- [ ] Review upcoming project staffing requisitions, required skills, and timelines from `delivery-manager`
- [ ] Ingest approved employee leave schedules and official public holidays from `people-operations-specialist`
- [ ] Check current studio bench roster and identify under-allocated team members
- [ ] Review skills matrix proficiencies to match specialized requirements to capable team members
- [ ] Confirm baseline target utilization benchmarks (target: 75% to 85% billable)

## While working
- [ ] Update Master Resource Allocation Matrix with proposed weekly hours per project
- [ ] Ensure no team member is scheduled for more than 2 concurrent client projects
- [ ] Enforce the 80% billable allocation ceiling (32 billable hours, 8 hours non-billable / L&D)
- [ ] Identify resource contention hotspots where demand exceeds available capacity
- [ ] Formulate balanced scheduling compromises; evaluate staggering project start dates
- [ ] Coordinate with `project-manager` to align allocations with sprint start dates
- [ ] Calculate forward-looking departmental utilization over rolling 4-week and 8-week horizons

## Before handoff
- [ ] Host weekly Resource Allocation Sync with department leads to lock next week's schedule
- [ ] Publish updated Master Resource Allocation Matrix to central repository
- [ ] Issue Staffing Requisition Alerts to `recruiting-specialist` for projected skill deficits
- [ ] Verify that all team and project references use valid roster slugs in backticks
- [ ] Confirm zero em dashes are present in any resource documentation
- [ ] Format handoff according to `orchestration/handoff-format.md` standards

## Stop and escalate if
- [ ] Critical project launch cannot be staffed due to complete exhaustion of internal capacity
- [ ] Department utilization exceeds 95% for 3 consecutive weeks, creating imminent burnout risk
- [ ] Two client engagements demand the same irreplaceable specialist with zero compromise flexibility
