# Proofreader: Checklist

## Before starting
- [ ] Editor's note shows zero open must-fix items (or the piece is a short post that skips editing per WF-04)
- [ ] Account style sheet and word list loaded, or a new style sheet started
- [ ] Source documents at hand: rate card or price list, client brief, contacts, permissions
- [ ] Target channel and format limits known

## While working
- [ ] Pass 1: spelling, grammar and punctuation read slowly in a different view
- [ ] Pass 2: every number and price checked against the source; ₹ and Indian grouping consistent
- [ ] Lakh and crore used consistently; no mixing with million
- [ ] Pass 3: every date checked for the correct weekday; festival dates verified for this year
- [ ] Pass 4: every person, business, place and product name checked against the brief and style sheet
- [ ] Pass 5: every link opened; destination, https and UTM parameters correct
- [ ] Click-to-chat links use `wa.me/91<number>`; `tel:` links use +91
- [ ] Pass 6: capitalisation, hyphenation, list punctuation and abbreviations consistent
- [ ] Pass 7: search for em dashes returns zero; no en dashes standing in for them
- [ ] Pass 8: character counts, line breaks and alt text checked for the channel
- [ ] Bilingual versions match on numbers, names, dates, contacts and links
- [ ] Corrections limited to errors; rewrites sent back as queries
- [ ] Quotes left unchanged; issues queried to the owner

## Before handoff
- [ ] Error log complete with location, type, severity and source checked
- [ ] Critical errors also reported to `content-calendar-manager` for derivatives
- [ ] Link test record with date and device
- [ ] Style sheet updated with new decisions
- [ ] Status set: proof clean only with zero open critical or major items
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A price, phone number or name differs from the source and no owner can confirm
- [ ] A link leads to a staging site, login page or a different business
- [ ] The piece arrives with open must-fix items from the editor
