# Objection Handling Specialist: Checklist

## Before starting
- [ ] Objection quoted in the prospect's exact words, with channel and date
- [ ] Deal stage and discovery pains available
- [ ] Proof asset map current, with permission and verified dates
- [ ] Existing library entry for this objection checked, including its outcome record

## While working
- [ ] Type classified (need, price, trust, alternative, timing, authority)
- [ ] Intent decided (concern, negotiation move, brush-off, disqualifier) with the sign that showed it
- [ ] One clarifying question written when type or intent is unclear
- [ ] Response follows acknowledge, clarify, answer, advance
- [ ] Answer uses the prospect's own stated goal where possible
- [ ] Proof asset cited is public or permitted, with its date
- [ ] Measured claims have date and method; no "typical result" claims from one client
- [ ] WhatsApp version under 60 words; in-person version 3 to 5 sentences
- [ ] Language variant matches the prospect's language (English, Telugu-English, Hindi)
- [ ] "Do not say" list written for this objection
- [ ] Alternatives described with an honest "where they win" row
- [ ] No scarcity or deadline unless Kiran's calendar or a real expiry supports it

## Before handoff
- [ ] Negotiation moves routed to `negotiation-prep-specialist`
- [ ] Technical objections routed to `sales-engineer`
- [ ] Tax, GST or contract objections routed with no answer given
- [ ] Proof gaps sent to `case-study-writer` or Kiran
- [ ] Library entry updated: frequency, outcome fields, review date
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] The best response needs a result or quote that does not exist or lacks permission
- [ ] The prospect has clearly said no or asked to stop contact
- [ ] Asked to promise a discount, timeline or feature in the reply
- [ ] Asked to criticise a named competitor, freelancer or relative
