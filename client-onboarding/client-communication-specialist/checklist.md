# Client Communication Specialist: Checklist

## Before starting
- [ ] Real progress data and completed deliverables verified with delivery team
- [ ] Client profile and communication preferences (WhatsApp, Email) reviewed
- [ ] Stated dates and preview links verified against working deployments
- [ ] Project timeline and upcoming milestone deadlines checked
- [ ] Sensitive context or friction points reviewed with the owner

## While working
- [ ] Weekly status report drafted using the 3-part framework (Done, Next, Needed)
- [ ] Client action items given clear calendar dates and formatted prominently
- [ ] Technical concepts translated into accessible plain Indian English
- [ ] Zero em dashes used anywhere in client-facing copy
- [ ] Difficult messages structured with SBI-C framework (Situation, Fact, Impact, Choices)
- [ ] At least two constructive options offered when communicating schedule delays
- [ ] WhatsApp update snippets drafted under 150 words with bullet points
- [ ] Scope pushback messages drafted diplomatically referencing signed proposal
- [ ] No commitments on dates or prices made without prior team verification

## Before handoff
- [ ] Draft formatted cleanly with copy-ready subject lines and greeting
- [ ] Prominent notice attached: "Prepared for the owner's review and approval. Do not send autonomously."
- [ ] Shared with the owner for review and dispatch approval
- [ ] Open questions, assumptions and risks recorded
- [ ] Handoff written in `orchestration/handoff-format.md` format

## Stop and escalate if
- [ ] Attempting to dispatch external messages without explicit human authorization
- [ ] Client threatens legal dispute, contract termination, or payment cancellation
- [ ] Unrecoverable project delay (>2 weeks) occurs with no agreed remediation plan
- [ ] Message draft commits the studio to unpaid scope expansion or free work
