# Presentation Designer: Checklist

## Before starting
- [ ] Audience, decision wanted and setting (live, WhatsApp PDF, LinkedIn) recorded
- [ ] Deck type chosen: presented, read, carousel or handout
- [ ] Narrative copy supplied by its owner (`proposal-writer`, `copywriter` or platform specialist)
- [ ] Every number supplied with a source; missing data listed with owner
- [ ] Pricing and scope tables come from `proposal-specialist` (if any)
- [ ] Permission recorded for any client logo, name or screenshot
- [ ] Output format, tool and length limit confirmed

## While working
- [ ] All slide titles written first as full-sentence assertions
- [ ] Titles read in order tell the whole argument; key message by slide 3
- [ ] Master set: 16:9 13.333 x 7.5 in, 0.5 in margins, fixed title zone, footer and source rail
- [ ] Two font families maximum, 4-step type scale
- [ ] Body text meets the deck type minimum (24 pt presented, 16 pt read, 28 pt carousel)
- [ ] Dense slides split rather than shrunk; nothing below 9 pt
- [ ] Each slide uses one pattern with evidence, not title-repeating bullets
- [ ] Charts chosen by message; one highlighted series; columns start at zero
- [ ] Source line on every data slide (owner, tool, date range)
- [ ] Real screenshots cropped to the point; no stock people
- [ ] Telugu or Hindi text checked for font availability and matra clipping
- [ ] Chart colours pass 3:1 and are not the only differentiator

## Before handoff
- [ ] Zero overflowing, clipped or overlapping objects
- [ ] Unique title on every slide; reading order set; alt text on meaningful images
- [ ] Accessibility checker run (PowerPoint or PDF) and result recorded
- [ ] Fonts embedded or PDF exported for portability
- [ ] Read-deck PDF size checked (target under about 10 MB) and file named by convention
- [ ] Storyline table and QA file saved with the deck
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A slide needs a number nobody has supplied
- [ ] Prices or terms appear that `proposal-specialist` and the owner did not approve
- [ ] Client material would be shown without permission
- [ ] You are asked to send or post the deck
