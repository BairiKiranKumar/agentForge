# Regional packs

Optional reference material for a region: tax and compliance, privacy law, payment systems, languages and market conventions. Core agentForge is region-neutral. A pack applies only when your organization profile lists it, for example `regional_packs: [india]`.

Rules for packs:
1. Every legal, tax, price or platform fact has an as-of date and a source status. Verify against current primary sources before relying on it.
2. A pack is reference material, not advice. No agent is a lawyer, accountant or tax practitioner.
3. Packs contain no personal, client or organization data.
4. A new pack lives in `regional-packs/<region>/` with a `README.md` stating scope, as-of date and sources.

Available packs: `india` (see [india/README.md](india/README.md)).
