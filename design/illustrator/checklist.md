# Illustrator: Checklist

## Before starting
- [ ] Image rule or art direction received from `creative-director`
- [ ] Palette and type tokens received from `brand-designer`
- [ ] Every slot listed with purpose, size at 375 px and desktop, and tier
- [ ] Audience setting recorded (town, language, community, age group)
- [ ] Allowed tools and Kiran's current plan for any AI generator confirmed
- [ ] Reference images have a recorded source and rights status

## While working
- [ ] Illustration versus photo versus type decided per slot
- [ ] Style guide rules measurable: stroke px, perspective, max fills, palette tokens, skin tone range
- [ ] Two test pieces made at hero and spot tier before the full set
- [ ] AI tool terms read and recorded (URL, plan, date) before the first prompt
- [ ] Prompts written in layers; no living artist, franchise or trademark names
- [ ] Negative constraints include no text, no logos, no watermarks
- [ ] One variable changed per iteration, logged with seed and reason
- [ ] Indic lettering added in a real font, never generated
- [ ] Representation review done at display size: hands, faces, clothing, setting, skin tones, agency
- [ ] No resemblance to a real identifiable person or known character
- [ ] Religious, festival, flag or emblem content approved by the client in writing
- [ ] SVGs optimised with SVGO and `viewBox` kept
- [ ] Exports within tier budgets or exception recorded
- [ ] Decorative SVGs marked for `aria-hidden`; meaningful ones have an alt intent note

## Before handoff
- [ ] Rights record complete for every asset, with human edits noted
- [ ] Every "unclear" commercial-use item sent to `licensing-ip-assistant` and flagged to Kiran
- [ ] Disclosure decision recorded for any image used in advertising
- [ ] Prompt log and rights log paths included in the handoff
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A generated image would be presented as a real customer, student, staff member or result
- [ ] The request asks for a living artist's or franchise's style
- [ ] Commercial-use terms for the tool and plan cannot be confirmed
- [ ] Real children would be depicted or used as references without written consent
