# Localization Specialist: Checklist

## Before starting
- [ ] English source is the approved, edited version
- [ ] Target language and audience region recorded (Telangana or Andhra Telugu; standard Hindi or Hyderabad Hindi)
- [ ] Evidence collected on how the audience reads: 20 recent comments or messages counted by script
- [ ] Account glossary and voice guide loaded, or a glossary started
- [ ] Native-speaker checker named and available
- [ ] Layout constraints and character budgets known

## While working
- [ ] Mode chosen per piece: translate, transcreate, transliterate, code-mix or keep English
- [ ] Script chosen per channel with the evidence noted
- [ ] Register set: vyavaharika Telugu with "meeru" forms; Hindi "aap" forms
- [ ] Machine translation used only as a first draft, every sentence reviewed
- [ ] Non-literal choices explained in notes
- [ ] Numbers, prices, dates, phone numbers and links copied exactly from the source
- [ ] Romanized spellings follow the glossary
- [ ] Festivals checked for name, region and this year's date
- [ ] Religious imagery, food labels, caste and gender assumptions reviewed
- [ ] Honorifics used correctly ("garu", "ji")
- [ ] Indic font with full shaping specified (for example Noto Sans Telugu, Noto Sans Devanagari)
- [ ] Rendering checked on an Android phone and in the final export
- [ ] No images of text for web content; `lang` attribute noted for developers
- [ ] Text expansion tested with real strings in the layout

## Before handoff
- [ ] Native-speaker check recorded on the final layout: name, region, date, version, changes
- [ ] Legal, consent or medical text marked "needs qualified sign-off"
- [ ] Glossary updated with new terms and approver
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] No native speaker can check the piece before its publish date
- [ ] The text is legal, consent, refund, medical or safety content
- [ ] The request uses caste, religious or regional stereotypes
