# Prospect Researcher: Checklist

## Before starting
- [ ] ICP version and date recorded
- [ ] Segment, area and target count confirmed
- [ ] Existing lead list, client list and do-not-contact list loaded for de-duplication
- [ ] Offer list read so every hook can map to an offer
- [ ] Paid data tools: none used unless Kiran approved credits

## While working
- [ ] Sourced 2 to 3 times the target count before filtering
- [ ] Hard-disqualified and duplicate candidates dropped with a recorded reason
- [ ] Only published business channels recorded, each labelled by type
- [ ] WhatsApp marked as confirmed only when the listing or site says so
- [ ] Exact-name and "name + city" searches done before marking "No site"
- [ ] Instagram bio link checked before marking "Social only"
- [ ] Mobile check done at 360 px width or on a mid-range Android, throttled, with date
- [ ] Facts collected with URL and date before any hook is written
- [ ] Hooks within freshness windows (posts 30 days, reviews 90 days, job posts 60 days)
- [ ] No hook uses customer names, health, finances or personal profiles
- [ ] Confidence High only with two independent sources
- [ ] Unknown fields written as "Not found", not blank
- [ ] B2B rows use company pages and job posts, no LinkedIn scraping

## Before handoff
- [ ] Every row has a source link and "seen on" date
- [ ] Zero duplicates against existing leads and clients
- [ ] Account briefs written for the top 5, each with a "don't mention" line
- [ ] Run summary includes candidates found, dropped and final count
- [ ] Shortfall against target count explained, if any
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff to `lead-qualification-specialist` in `orchestration/handoff-format.md` format with `authorization: none`

## Stop and escalate if
- [ ] Asked for owners' personal numbers, home addresses or family details
- [ ] Asked to scrape Maps, Instagram or LinkedIn, or to use a bought list
- [ ] Research would require logging in, bypassing a wall or messaging the business
- [ ] A paid tool would spend credits without Kiran's approval
