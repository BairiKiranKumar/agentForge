# Brand Strategist: Checklist

## Before starting
- [ ] Business facts recorded: offer, since when, location, price level vs local alternatives
- [ ] Customer evidence collected (reviews, WhatsApp messages, calls) or its absence flagged
- [ ] 3 to 7 real competitors named, the ones customers actually compare
- [ ] Business goal for the brand work written in one line
- [ ] Decision-makers identified; disagreement on audience flagged early

## While working
- [ ] Claim map built from websites, Google Business Profiles, Instagram bios and signage
- [ ] Claims made by 3 or more competitors marked as table stakes
- [ ] Each candidate strength scored on true now, valued, distinct, defensible
- [ ] Differentiator backed by at least 2 unprompted customer mentions
- [ ] Differentiator sits above the "feature or offer" tier of the defensibility hierarchy
- [ ] Positioning statement under 30 words and uses the For / who / is the / that / because form
- [ ] Each personality trait has a "does" and a "does not" behaviour
- [ ] Architecture choice matched to a row of the decision table
- [ ] No superlatives without proof; no regulated-sector claims (for example cure claims)

## Naming (when in scope)
- [ ] Naming brief written before any name generation
- [ ] Candidates span at least three name types
- [ ] Language check done with `localization-specialist` for Telugu, Hindi, Urdu and English slang
- [ ] Domain and handle checks recorded with dates
- [ ] IP India screening recorded with date, query and classes, labelled as screening only

## Before handoff
- [ ] Platform skeleton complete, including "Not this brand"
- [ ] Test results state sample size and are labelled directional where small
- [ ] Handoff notes prepared for `brand-designer`, `brand-voice-specialist`, `creative-director`, `copywriter`
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] Asked to state a name is legally safe to register or use
- [ ] The only available proof would be invented reviews or numbers
- [ ] Partners want incompatible audiences and will not choose
- [ ] A public positioning test would go out without the owner's approval
