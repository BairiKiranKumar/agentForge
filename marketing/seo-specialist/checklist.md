# SEO Specialist: Checklist

## Before starting
- [ ] Business type, service area and priority services confirmed in writing
- [ ] Languages of search identified (English, Telugu, Hindi, Tamil, Kannada, transliterated)
- [ ] Search Console export for the last 3 months received, or "no data" recorded in the output
- [ ] Current page list obtained from the sitemap export or site map shared by the client
- [ ] Competitor list of 3 to 5 sites recorded, with the reason each was chosen

## Keyword work
- [ ] Each keyword has a stated search intent (informational, commercial, transactional or navigational)
- [ ] Customer phrases from WhatsApp, reviews or call logs were compared with the keyword list
- [ ] Every page has exactly one primary query in the keyword map
- [ ] Transliterated and regional-language variants recorded as separate queries where searched
- [ ] Volume figures carry the tool name and the date pulled, or are marked "not measured"

## On-page review
- [ ] Title tag length checked: 50 to 60 characters, primary query near the front
- [ ] Meta description length checked: 120 to 160 characters, unique per page
- [ ] One H1 per page, containing the primary query in natural language
- [ ] Heading levels in order with no skipped levels
- [ ] First 100 words answer the query and name the service area
- [ ] Images have descriptive file names and alt text
- [ ] Each target page has at least 3 internal links from related pages with descriptive anchor text

## Planning and handoff
- [ ] Striking-distance pages (positions 8 to 20) checked before any new page is proposed
- [ ] Cannibalization pairs listed with a merge, redirect or retarget decision
- [ ] Backlog items scored and each item has an owner role
- [ ] Content briefs follow the section 6 template with facts, sources and as-of dates
- [ ] Redirect or merge recommendations sent to `technical-seo-specialist` for review
- [ ] Map and listing tasks sent to `local-seo-specialist`
- [ ] Re-check date set (8 weeks) with the metric to compare

## Stop and escalate if
- [ ] The client asks for a guaranteed ranking, traffic number or position
- [ ] A recommended title or copy would make a medical, legal or financial claim without a source
- [ ] The client wants more than 10 city-plus-service pages with near-identical text
- [ ] Access to Search Console is refused or unclear; do not use another person's login
- [ ] A competitor's private data appears in the request
