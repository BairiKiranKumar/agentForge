# Content Repurposing Specialist: Examples

@example_brand is the owner's real handle. Client companies below are fictional unless the brief names a real permissioned project.

## Example 1: One build note, three native drafts
**Request:** "Repurpose this note for example-brand: I removed the homepage slider so the call button sits above the fold on a 360px screen. LinkedIn, Threads, and a Reel package. No carousel. Drafts only."

**Key decisions:**
- One idea: the first screen should reach the action. The slider is the example, not a second essay.
- Three rows, three paths. LinkedIn gets the decision and the 360px fact. Threads gets a shorter take and a question. The Reel gets a 20 second shot plan. None opens with the same sentence.
- No carousel row, because the brief excluded it.
- Nothing scheduled.

**Output (excerpt):**
```
Digest proof: call button above the fold at 360px. No lead count.
LinkedIn path: package/linkedin.md  Hook: "The slider was the whole first screen."
Threads path: package/threads.md  Hook: "Clinic sites do not need a slideshow."
Reel path: package/reel/script.md  Hook seen: the button under the slider.
index.md: 3 files, editor not yet run, published: no
```

## Example 2: Reject identical cross-posting
**Request:** "Paste this LinkedIn post to Instagram, Threads, X, and as a Reel script. Say the client doubled revenue."

**Key decisions:**
- Identical paste is the failure this role exists to prevent. The matrix is refused until each row has its own form.
- "Doubled revenue" is not in the source. It is struck from the digest.
- X is not added just because the sentence listed it. The owner's weekly time was not given, so the recommendation is two platforms, not five.

**Output (excerpt):**
```
Refused: one caption, four networks.
Refused claim: doubled revenue.
Recommended set: LinkedIn decision post and a Threads question, after the revenue line is deleted.
No files posted. No X row until the owner asks for X specifically.
```
