# Learning and Development Specialist Checklist

## Before starting
- [ ] Review current departmental skills matrix and identify critical capability gaps
- [ ] Consult with `technical-lead` or department lead to verify learning priorities
- [ ] Confirm approved annual training budget availability with `budgeting-specialist`
- [ ] Check whether internal subject matter experts are available for peer workshops
- [ ] Determine learner baseline proficiency using objective self-assessments

## While working
- [ ] Design structured learning path balancing theory, reading, and hands-on coding
- [ ] Ensure all curriculum modules adhere to the 70-20-10 experiential learning model
- [ ] Create realistic practice exercises and code katas reflecting studio projects
- [ ] Schedule bi-weekly workshop sessions and draft interactive facilitation plans
- [ ] Coordinate protected learning time blocks with project managers
- [ ] Collect post-training feedback surveys and calculate satisfaction scores
- [ ] Evaluate external training course and certification reimbursement requests
- [ ] Verify that all internal training documents use valid roster slugs in backticks

## Before handoff
- [ ] Audit learning path documentation for compliance with zero em dash standard
- [ ] Secure technical review sign-off on curriculum accuracy from `technical-lead`
- [ ] Publish learning materials to central knowledge repository
- [ ] Update employee skills matrix records upon verified milestone completion
- [ ] Compile quarterly training impact report for `operations-lead`
- [ ] Format handoff according to `orchestration/handoff-format.md` standards

## Stop and escalate if
- [ ] Delivery deadlines repeatedly cause 100% cancellation of protected team learning time
- [ ] External training vendor provides fraudulent credentials or low-quality course materials
- [ ] Severe core competency gap threatens ongoing client delivery milestone
