# Editor: Checklist

## Before starting
- [ ] Brief available: goal, audience, key message, CTA, channel, length
- [ ] Sources and permission references from the writer received
- [ ] Voice guide located (or noted as absent)
- [ ] Whole draft read once without editing
- [ ] Edit mode chosen and stated with evidence: rebuild, restore or point edit

## While working
- [ ] Key message written in one sentence from the draft and compared with the brief
- [ ] Reverse outline made for pieces over 300 words
- [ ] Cuts marked: repeats, tangents, throat-clearing intros, tidy closers
- [ ] Gaps marked: unanswered objection, missing proof, missing next step
- [ ] Each claim checked: support exists and actually shows the claim
- [ ] False causation and contradictions flagged
- [ ] Every fact logged with status: verified, needs source, remove
- [ ] Time-sensitive facts carry an as-of date
- [ ] Fact-check requests sent early with owner and deadline
- [ ] Channel structure test applied (page, article, case study, proposal, script, post, docs)
- [ ] Line edits keep the writer's vocabulary; nominalisations and long sentences fixed
- [ ] AI tells removed by returning to facts, not by synonym swaps
- [ ] Voice drift noted for `brand-voice-specialist`, not imposed
- [ ] Return-to-writer threshold checked (about 40% of paragraphs needing rewrite)

## Before handoff
- [ ] Leave-it-alone check done; unjustified changes reverted and counted
- [ ] Editor's note written: mode, verdict, must fix, should fix, consider
- [ ] Zero open must-fix items before passing to `proofreader`
- [ ] Zero em dashes in the edited draft
- [ ] No new facts added without a cited source
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A regulated claim (health, admissions, financial return) is central to the piece
- [ ] The client insists on a claim you have marked must fix
- [ ] A third revision round with the same writer is needed
