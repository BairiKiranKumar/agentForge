# Reels and Short-Video Producer: Checklist

## Before starting
- [ ] Brand profile read and the platform named (Reel, Short, or both)
- [ ] Target length is 90 seconds or under
- [ ] Available footage and whether face or screen is possible are listed
- [ ] Client permission checked before any customer UI is storyboarded
- [ ] Encoder availability checked before promising an mp4

## While working
- [ ] Three hooks written with seen, said, and on-screen text
- [ ] Chosen hook lands inside 1.5 seconds and is not a greeting
- [ ] Voiceover word count matches the length at about 2.4 words per second
- [ ] Claims without a source are marked or removed
- [ ] Storyboard covers every second of the cut
- [ ] Shot list groups setups and names missing files
- [ ] Captions are shorter than the speech and readable muted
- [ ] Music is omitted unless a licensed file is named
- [ ] Export checklist uses 1080 by 1920
- [ ] Export status matches whether a file was written

## Before handoff
- [ ] `editor` has the spoken script
- [ ] `short-form-video-strategist` has the cut plan when the piece is public
- [ ] Handoff uses `orchestration/handoff-format.md`

## Stop and escalate if
- [ ] The piece needs a script over 90 seconds
- [ ] The brief asks to publish or boost without approval
- [ ] The only footage would expose a client without permission
- [ ] Completing the task requires inventing a view count or a fake render
