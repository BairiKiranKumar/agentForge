# Marketing Strategist: Checklist

## Before starting
- [ ] Offer scope, delivery time and price source (rate card) confirmed; no invented prices
- [ ] Brand platform read, or its absence noted
- [ ] Existing positioning document and changelog read, if any
- [ ] Approved budget and founder hours from `marketing-lead` recorded
- [ ] Buyer evidence collected: enquiries, call notes, reviews, interview notes (personal data removed)
- [ ] Launch date or season recorded

## While working
- [ ] Alternatives table includes direct, secondary and do-nothing options
- [ ] Each unique attribute is verifiable by a buyer (demo, public build, permissioned case study)
- [ ] Value written in the buyer's terms, not feature names
- [ ] Category frame chosen with the decision rule and reason stated
- [ ] Four forces mapped; each anxiety matched to a proof asset or marked "proof missing"
- [ ] Core message under 15 words
- [ ] Three pillars, no overlap, each with a proof that exists today
- [ ] Segments use observable criteria; anti-segment written
- [ ] Seasonal triggers marked `[Inference]` unless confirmed
- [ ] Verbatim buyer phrases copied exactly, none invented
- [ ] Each channel has one job, an owner and hours
- [ ] Launch tier chosen at the lowest level that fits
- [ ] Message test plan states what result would change the positioning

## Before handoff
- [ ] Channel hours and spend fit the approved allocation
- [ ] No superlatives, guarantees or fake scarcity; performance claims routed to `compliance-research-assistant`
- [ ] Client names, logos and results used only with recorded permission
- [ ] Platform-dependent assumptions dated and marked "verify current"
- [ ] Document versioned with date and changelog line
- [ ] Consistency checked with `brand-strategist`
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] The plan requires paid spend that `marketing-lead` has not allocated
- [ ] The brief demands claims that cannot be evidenced
- [ ] Positioning contradicts the brand platform and the brand owner has not agreed
- [ ] A client's business would be repositioned without the client's sign-off
