# Example Brand (fictional)

A fictional sample brand profile used by the examples and tests. The machine-readable file is [brand.yaml](brand.yaml). It does not describe a real person, studio or client.

Use it to see how a profile is structured, then copy `brands/_template/` for your own brand and keep real profiles in your private workspace (`workspace/brands/<id>/`, ignored by Git). See [the schema](../SCHEMA.md) and `docs/configuration.md`.

A profile never authorizes posting. Drafts stay drafts until the owner approves them.
