# Brand Designer: Checklist

## Before starting
- [ ] Brand platform with personality traits received, or a short equivalent from Kiran
- [ ] Business name spelling confirmed in writing in every script required
- [ ] Application list known: signage, print items, avatars, website, uniforms or vehicles
- [ ] Existing assets reviewed; elements customers recognise noted
- [ ] Refresh vs rebrand decided using the decision table
- [ ] Local category scan done (nearby Google Maps listings in the same category)

## While working
- [ ] Trait-to-form mapping written before sketching
- [ ] Two or three concepts that differ in idea, not only in colour
- [ ] No category cliché mark unless the platform calls for it and the execution is distinct
- [ ] Symbol tested in a 48 px circle crop
- [ ] Symbol tested as a 16 px favicon
- [ ] One-colour, reversed and photocopy-style tests done
- [ ] Bilingual lockup balances scripts by visual weight
- [ ] Clear space defined from a logo-internal unit
- [ ] Minimum sizes set for screen (px) and print (mm)
- [ ] Palette has core, supporting and a tinted neutral ramp
- [ ] HEX, RGB and CMYK given; CMYK marked "proof with printer"
- [ ] Every approved text pair meets WCAG 2.2 AA with ratio shown
- [ ] Indic typefaces are script-native; line height raised for Indic body text
- [ ] Font licences recorded with source links

## Before handoff
- [ ] Concepts and final shown on at least 4 real applications
- [ ] Guidelines include 6 or more misuse panels and a file index
- [ ] Asset kit exported in SVG, PNG 512/1024, PDF, favicon set, avatar files
- [ ] File names follow `<brand>-<variant>-<colour>.<ext>`
- [ ] Brand values packaged for `design-systems-specialist`
- [ ] Assumptions, open questions and risks listed
- [ ] Handoff written in `orchestration/handoff-format.md` format with evidence

## Stop and escalate if
- [ ] A requested symbol carries religious, community or political meaning
- [ ] The client asks to copy or closely imitate another brand's mark
- [ ] A font's licence for commercial or logo use cannot be verified
- [ ] Anyone asks you to confirm the logo is trademark-safe
