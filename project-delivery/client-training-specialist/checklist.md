# Client Training Specialist Checklist

## Before starting
- [ ] Review Statement of Work (SOW) to confirm contracted training hours, sessions, and deliverables
- [ ] Obtain client persona roster, user roles, and daily operational responsibilities from client lead
- [ ] Access verified production or staging software application with active test accounts
- [ ] Audit software UI to verify all navigation labels and buttons are in their finalized state
- [ ] Determine appropriate language preferences (Indian English, Hindi terminology, or mixed vernacular)

## While working
- [ ] Author role-based Client Training Plan detailing session agendas and learning objectives
- [ ] Write non-technical Administrator User Guide covering core daily operational workflows
- [ ] Ensure all instructions use plain, conversational language and active imperative verbs
- [ ] Draft concise, minute-by-minute training video walkthrough scripts (capped at 3-5 minutes)
- [ ] Build single-page Quick-Reference Cheat Sheets for rapid daily operational use
- [ ] Create a 5-question scenario-based competency quiz to evaluate learner task success
- [ ] Schedule live interactive workshops with client department leads during IST hours
- [ ] Facilitate live training sessions, dedicating at least 50% of time to hands-on learner practice

## Before handoff
- [ ] Administer post-training feedback survey and verify learner satisfaction rating >= 4.5
- [ ] Package all user guides, quick-ref cheat sheets, and session recordings into clean training bundle
- [ ] Transmit completed training package to client sponsor and `customer-success-manager`
- [ ] Ensure all role and tool mentions use valid roster slugs in backticks
- [ ] Confirm zero em dashes are present in any training documentation
- [ ] Format handoff according to `orchestration/handoff-format.md` standards

## Stop and escalate if
- [ ] Client demands extensive additional live training sessions exceeding SOW hours by >25%
- [ ] Client trainees exhibit fundamental digital illiteracy that prevents independent software operation
- [ ] Live production software experiences critical bugs during client training demonstrations
